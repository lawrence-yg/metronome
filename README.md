# 节拍器

一个单文件的网页节拍器：双击 `index.html` 就能用，**不需要联网，也不需要安装任何东西**。

## 用法

1. 双击 `index.html`，或直接把文件拖进浏览器
2. 调速度：**点数字直接输入**，或拖动下方滑块（20–300 BPM）
3. 选拍号；点拍点可以单独开关重音（第一拍恒为重音）
4. 点「播放 / 暂停」

设置会自动记住，下次打开还是上次的速度和拍号。

## 特性

- **单文件、零依赖**：一个 HTML 装下界面、样式和逻辑，离线可用
- **速度范围 20–300 BPM**，点数字输入或拖滑块
- **拍号可选**，每拍可单独开关重音
- **节奏型可展开**：选择每拍内部的击打方式
- **时间精度**：用 Web Audio 提前 120ms 排程，不依赖 `setInterval` 的抖动，速度快时也不漂
- **键盘与无障碍**：速度和滑块都有 aria 标注

## 说明

音色是代码合成的短促滴声——重拍略高、略响。要换音色改源码里的合成参数即可，没有外部音频文件。

## 在线使用

仓库已包含 `index.html`，开启 GitHub Pages 后可以直接在线使用，无需下载。
